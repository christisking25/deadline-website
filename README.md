# Deadline: marketing site

Static marketing site for the Deadline iOS app. Lives at **hitdeadline.com**.

## Stack

- Vite 6 + React 18
- Tailwind CSS v4 (via `@tailwindcss/vite`)
- Framer Motion for scroll reveals, the escalation scrub, and the marquee
- Zero runtime dependencies beyond those. No CMS, no analytics, no tracking.

## Commands

```bash
npm install
npm run dev      # local dev server
npm run build    # static build into dist/
npm run preview  # serve the built dist/ locally
```

**The build output folder is `dist/`.** That is the folder GitHub Pages serves.

## Design system

`design-system/deadline/MASTER.md` is the source of truth for color, type,
motion, and the pre-delivery checklist. It was generated with
`ui-ux-pro-max`, then merged with the Deadline brand rules. Brand rules win on
conflicts, and every override is marked in the file.

Regenerate the base system with:

```bash
python3 ~/.claude/skills/ui-ux-pro-max/scripts/search.py \
  "productivity app screen time habit accountability dark premium" \
  --design-system --persist -p "Deadline"
```

Note that this overwrites the generated sections. The brand overrides are
hand-merged, so re-run it only if you intend to redo that merge.

## Assets

- `public/favicon.svg` is the hourglass mark, gold on dark.
- `public/app-icon.png` is copied from the iOS project's `AppIcon.appiconset`
  and used as the Apple touch icon.
- `public/og-image.png` is generated by `scripts/make-og.py` (needs Pillow).
  Re-run it if the headline or brand colors change.
- `public/CNAME` holds the custom domain. Do not delete it: GitHub Pages reads
  this file to keep hitdeadline.com bound to the site.

## Before launch

Three things in the code are deliberately unfinished and marked with comments:

1. **Testimonials** (`src/sections/Testimonials.jsx`) are placeholder quotes.
   Replace with real App Store reviews or delete the section. Do not ship
   invented quotes as real reviews.
2. **Pricing FAQ** (`src/sections/FAQ.jsx`) has a TODO on the "Is it free?"
   answer. Fill in the real model and update the FAQ JSON-LD in the same file.
3. **App Store links** are `href="#"` in `src/sections/Hero.jsx` and
   `src/sections/FinalCTA.jsx`. Point them at the real listing.

## Accessibility and motion

- Dark theme only, by design. All text pairs are documented and verified at
  4.5:1 or better in MASTER.md.
- `prefers-reduced-motion: reduce` disables the marquee, parallax, scroll
  scrub, pulsing glows, and count-up numbers. Counters print their final
  value and every section renders in its final readable state.
- Keyboard: skip link, visible focus rings, arrow-key navigation in the FAQ,
  Escape closes the mobile menu.
